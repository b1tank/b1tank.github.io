OpenSnipping brings screenshot capture, cropping, annotation, and screen recording into the browser. Captured media stays on the device: there is no backend, account, telemetry, or upload step.

The web version uses plain HTML, CSS, JavaScript modules, Canvas, MediaRecorder, and browser capture APIs. It is separate from the native Tauri/Rust OpenSnipping application.

The live demo on this site is a versioned static snapshot. The existing Yummy Jars deployment remains independent and unchanged.
