Deskpal is a C-native MCP server that gives AI agents eyes and hands for Linux desktop applications. It combines capture-bound screenshots, OCR, AT-SPI accessibility, semantic actions, pixel input, and private Xvfb verification sessions.

The design emphasizes safe, observable actions: stable window identity, explicit foreground approval, bounded semantic state, input arbitration, and verified visual or semantic postconditions. The repository will become public when the initial release is ready.
