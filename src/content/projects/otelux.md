OTelux receives traces, logs, and metrics, keeps them on the user’s machine, and presents them through one visual workbench. Coding agents can inspect the same evidence through read-only MCP tools.

The project is designed around one local runtime shared by a desktop app, agent plugins, direct MCP integration, and a CLI. The repository is private while the first public release is being prepared.
