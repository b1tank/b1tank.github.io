Learn Ghostty is a learn-by-doing course for building an end-to-end mental model of a modern terminal emulator. Ghostty’s pinned source is the textbook, the browser is the visual learning cockpit, and Pi acts as a teacher alongside the local course.

The public reading mode includes lessons, interactive diagrams, browser-local progress, and pinned source excerpts. The complete local camp adds durable progress, source navigation, editor integration, allowlisted native labs, and agent-guided explain-backs.

The project is built with VitePress, Vue, Markdown, and a narrow local Node service. It is intentionally developed one complete lesson at a time instead of generating a large course before it has been used.
