BoringBlog is a small publishing system for family stories: invited authors write with a rich-text editor and readers get a clean public site with posts, tags, authors, images, and embedded video.

It runs on Next.js and PostgreSQL with Prisma, Azure Container Apps, Blob Storage, Key Vault, email delivery, OpenTelemetry, infrastructure as code, and end-to-end tests.
