Learn C follows *The C Programming Language* from beginning to end, rewriting each section in approachable language and pairing it with a runnable browser editor.

The application uses plain HTML, CSS, and JavaScript. C examples compile through a WebAssembly toolchain in the browser; progress and edited code stay in local storage. There is no account, tracking, analytics, or application backend.

The course keeps K&R’s compact progression while calling out places where contemporary C practice differs from the original text.
