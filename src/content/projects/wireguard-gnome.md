The extension discovers WireGuard configurations, provides one-click tunnel controls, and displays endpoints, handshakes, and transfer statistics from `wg show`.

It synchronizes with command-line state and uses Polkit for privileged operations. Packaging and documentation still need another polish pass before a wider release.
