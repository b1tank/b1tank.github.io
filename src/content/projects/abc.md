ABC Balloon turns early learning into a small, tactile browser game. It includes free play, spelling challenges, math challenges, English and Chinese interfaces, and progress stored locally in the browser.

The application is written in plain HTML, CSS, and JavaScript with the Canvas API. It has no backend and no runtime dependencies.

The live demo on this site is a versioned static snapshot. The existing Yummy Jars deployment remains independent and unchanged.
